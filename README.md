# Tokopedia Web Scraping with Python

# Project Overview
This project demonstrates web scraping techniques using Python to extract product information from Tokopedia.
The project collects product titles and prices, records the scraping date, and stores the extracted information for basic product price tracking.

# Tools & Libraries
- Python
- Requests
- BeautifulSoup
- Pandas
- CSV
- Datetime
  
# Project Objectives
- Extract product information from Tokopedia.
- Collect product titles and prices.
- Record product prices along with scraping dates.
- Store extracted data in CSV format.
- Practice web scraping and data collection using Python.

# Project Workflow
1. Import the required Python libraries.
2. Send HTTP requests to the Tokopedia product page.
3. Parse HTML content using BeautifulSoup.
4. Extract product titles and prices.
5. Record the current date.
6. Export the extracted information into CSV format.
7. Inspect the collected data using Pandas.

# Project Outcome
Developed a basic web scraping workflow to collect product information from Tokopedia and store the extracted data for further analysis.
